# Hi, I'm Carlos 👋

**Application Security Professional** · Web Pentesting · Bug Bounty · Vulnerability Research

I break web apps (with permission) so they can be fixed before someone with
bad intentions finds the same bugs. My work is hands-on, methodical and
always authorized.

---

## 🔍 What I do

- 🌐 **Web application pentesting** — access control and authorization flaws
  (IDOR is a favorite), authentication and sessions, injection, business logic
- 🔌 **API security testing** — object-level authorization and data exposure
- 📦 **Open-source vulnerability research** — responsible reporting to
  maintainers and CVE coordination via GitHub Security Advisories
- 📝 **Technical reporting** — clear, reproducible findings with CVSS 3.1 and
  OWASP WSTG classification
- 📱 **Mobile security (Android / iOS)** — currently learning, following
  OWASP MASVS / MASTG

## 🧭 How I work

- 🖐️ **Manual first** — hands-on testing with browser DevTools and Burp Suite Pro, request by request, no automated scanning
- 🎯 **Scope-driven** — every test starts from a defined scope and
  authorization
- 🧪 **Minimal PoC** — the smallest safe proof of impact, nothing more
- 🤝 **Responsible disclosure** — private report to the owner first, public
  only after a fix or an agreed timeline
- ✅ **Evidence over assumptions** — I'd rather send one verified finding than
  ten maybes

## 🛠️ Tooling

`Burp Suite Pro` · `Kali Linux` · `Browser DevTools` · `Frida` · `adb` · `apktool`
